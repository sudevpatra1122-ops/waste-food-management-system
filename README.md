# waste-food-management-system

♻️ A smart food donation platform built to manage surplus food, connect donors with recipients, and promote sustainable food distribution.

## 🚀 Live Demo
[View Live Demo on Streamlit Cloud](https://waste-food-management-system-kzpbbzvvmdwwzcxxxegfyk.streamlit.app)

## 📋 Features
- 📊 **Overview Dashboard** - Real-time analytics and KPIs
- 🔍 **Exploratory Data Analysis** - Detailed data insights and distributions
- ⚠️ **Expiry & Risk Predictor** - AI-powered risk scoring for food items
- 📈 **Trends & Forecasting** - Waste predictions and trends analysis
- 🗃️ **Data Explorer** - Interactive data tables for donors, claims, and listings

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **Data Processing**: Pandas, NumPy
- **Visualization**: Matplotlib, Seaborn
- **Database**: SQLite (optional)

## 🎯 How It Works
1. **Food Donors** list surplus items with quantity and expiry details
2. **Risk System** evaluates expiry timeline and food decay rates
3. **Recipients** claim available food from the platform
4. **Analytics Dashboard** tracks impact, trends, and waste reduction

## 🌟 Key Metrics
- Total Food Listed (kg)
- Estimated Waste Reduction
- High-Risk Items Alert
- Claim Fulfillment Rate
- Active Donor Network
